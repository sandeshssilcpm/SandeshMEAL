GWT Nepal – Monitoring and Evaluation Dashboard Portal
Welcome to the GWT Nepal Monitoring and Evaluation Dashboard Portal.

This portal provides a central platform for accessing, reviewing and analysing monitoring and evaluation data across GWT Nepal's projects. It brings together project-specific dashboards to support progress tracking, performance assessment, outcome measurement and evidence-based decision-making.

Through accessible data and interactive visualisations, the portal aims to strengthen accountability, improve programme quality and support organisational learning.
